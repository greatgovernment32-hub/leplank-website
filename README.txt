EASY EDITING
This version includes Decap CMS at /admin/. Once the site is connected to GitHub + Netlify and Netlify Identity/Git Gateway is enabled, you can log in and add new gallery photos without editing HTML.

To add a project:
1. Open your website and go to /admin/.
2. Log in.
3. Open Gallery and choose Kitchens, Closets / Wardrobes, Timber, Bathrooms, or Offices & Studies.
4. Click Add Project.
5. Upload the project photo, enter a caption, then Save/Publish.
6. Netlify redeploys the site and the new photo appears in that gallery.

HOSTING / CMS SETUP
The CMS is configured for Decap CMS with Netlify Git Gateway. The repository must be hosted on GitHub and the site deployed through Netlify. In Netlify, enable Identity and then Git Gateway. Use Invite only for CMS access and invite the business owner/editor.

CONTACT FORM
The Contact Us form is configured as a Netlify Form. In Netlify, add a form notification so enquiries are emailed to leplanksa@gmail.com.

IMPORTANT
Do not share the /admin/ login with customers. Only trusted editors should have CMS access.
